等一下，改用 sync-engine 更简单：

用 Bash 工具执行：
```
{{NODE_PATH}} {{SYNC_ENGINE_PATH}} --config {{CONFIG_PATH}}
```

同步引擎会自动：
- 读取 config.json 中启用的 IM 平台配置
- 并行拉取所有群聊和单聊的最近消息
- 用关键词匹配提取工作任务
- 写入 {{TASKS_JSON_PATH}}
- 在 stdout 输出 JSON 格式的同步结果摘要

第二步——读取同步结果：

解析 stdout 的 JSON 输出，获取以下字段：
- success: 是否成功
- conversations: 拉取的会话数
- messagesScanned: 扫描的消息总数
- tasksExtracted: 提取的任务数
- connectors: 各平台的同步状态

同时用 Read 工具读取 {{TASKS_JSON_PATH}} 确认任务已写入。

第三步——输出到对话窗口（极简，尊重用户注意力）：

1. [来源] 任务描述（如有截止日期标注）
2. [来源] 任务描述

【无新任务时】只输出一句：
最近{{HOURS_back}}小时无新增任务，安心干活。
